# Explainable AI for Medical Image Classification

## Overview
This repository is intended to support reproducible experiments in medical image classification and explainability. It should be adapted only after the selected public repository, dataset, license, and research question have been reviewed.

## Project status
Initial planning/documentation stage. Replace this status with verified implementation details as work progresses.

## Goals
- Reproduce a clearly defined baseline.
- Compare selected models using a fixed evaluation protocol.
- Investigate explainability methods such as Grad-CAM when appropriate for the model and modality.
- Report class-wise performance, limitations, and failure cases.
- Provide reproducible setup and inference instructions.

## Before running
1. Read `CLAUDE.md` and `PROJECT_PLAN.md`.
2. Review the source repository and its license (`REPOSITORY_ANALYSIS.md`).
3. Follow `DATASET_GUIDE.md` for approved data access and splits.
4. Install dependencies in an isolated environment.
5. Run tests before training.

## Results
Do not add performance claims until the experiment has actually run. Record configurations and outputs in `PROGRESS.md` and summarize verified results here.
