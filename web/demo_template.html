Pneumonia classifier with an occlusion heatmap

Load a grayscale chest X-ray or pick one of the validation images. A small CNN trained on PneumoniaMNIST scores it, then covers the image patch by patch to show which areas move the score.

Research use only. This is not a medical device and the output is not a diagnosis. The model saw only 28 × 28 px pediatric X-rays from one hospital, so other images may be scored unreliably. Nothing you load leaves this page.

What runs here

A 3-block CNN with {{NPARAMS}} parameters (configs/small_cnn.yaml, seed 0), trained on GitHub Actions on the real PneumoniaMNIST data. Its weights are embedded in this page and run in plain JavaScript; the output was checked against PyTorch on the same inputs.

This run, validation split, threshold 0.5: AUROC {{V_AUROC}}, sensitivity {{V_SENS}}, specificity {{V_SPEC}}.

How good is this configuration

On the held-out test set, evaluated once, the same configuration over 3 seeds scored AUROC {{T_AUROC}}, sensitivity {{T_SENS}} and specificity {{T_SPEC}} at threshold 0.5. Validation numbers are optimistic because the validation split was cut by image, not by patient.

Limits

  • Every image is centre-cropped and shrunk to 28 × 28 px, so fine detail is gone.
  • Trained only on pediatric X-rays from one hospital; adult or other-scanner images are out of distribution.
  • The heatmap shows where covering the image lowers the predicted class's score. It is not clinical reasoning.
  • Colour images are rejected, as in medxai/infer.py.
